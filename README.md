# Dream World

떠올린 꿈을 단어 4~10개로 적으면, AI가 단어 사이의 관계를 정하고 그 관계대로 3D 공간을 지어 보여 주는 Windows 앱입니다. 공간을 둘러본 뒤 떠올린 꿈과 얼마나 닮았는지 평가해 주세요.

## 내려받기

**[DreamWorld-Setup.exe 내려받기](https://jonathan-listed-consult-assembly.trycloudflare.com/download/setup)** (설치 파일, 권장)

설치 없이 쓰려면: [DreamWorld-trial.zip](https://jonathan-listed-consult-assembly.trycloudflare.com/download) (압축을 푼 뒤 DreamWorld.exe 실행)

## 실행 방법

1. DreamWorld-Setup.exe를 실행해 설치합니다. 관리자 권한은 필요 없습니다.
2. Windows가 'PC 보호' 경고를 띄우면 '추가 정보'를 누른 뒤 '실행'을 누릅니다. 코드 서명이 아직 없어서 뜨는 경고입니다.
3. 시작 메뉴나 바탕화면의 Dream World를 엽니다.
4. 단어를 4~10개 넣고 '공간 만들기'를 누릅니다. 1~3분쯤 걸립니다.
5. ① 관계 공간과 ② 세부 공간을 오가며 보고, '내 꿈과 비교해 평가하기'로 1~5점과 의견을 보내 주세요.

## 안내

- 공간 만들기는 한 사람당 정해진 횟수까지입니다. 만든 공간에 단어를 더하는 것도 공간마다 횟수가 정해져 있습니다. 만들기에 실패하면 횟수가 줄지 않습니다.
- 인터넷 연결이 필요합니다. 입력한 단어는 공간을 만들기 위해 Dream World 서버와 OpenAI로 전송됩니다. 이름, 연락처 같은 개인정보는 넣지 마세요.
- 평가 점수와 의견은 연구와 개선을 위해 서버에 저장됩니다.
- 사양: Windows 10/11 64비트, DirectX 11 이상 그래픽카드. Python이나 API 키는 필요 없습니다.
- 지우려면: 설정 > 앱 > Dream World > 제거.
